# PRD 028: Standarisasi Sinkronisasi Social Proof (Rating & Terjual) di Halaman "Semua Produk"

## 1. Konteks Masalah
Pada implementasi PRD-027, fitur Social Proof (Bintang Rating & Jumlah Terjual) sudah berhasil tampil di halaman beranda (khususnya section Paling Disukai). Namun, ketika user menavigasi ke halaman/section "Semua Produk", elemen Social Proof tersebut hilang. 

## 2. Analisis Akar Masalah (Root Cause)
Komponen `ProductCard` sudah siap menerima props `averageRating` dan `totalSold`, tetapi fungsi pemanggilan data (Data Fetching / Prisma Query) khusus untuk halaman "Semua Produk" belum diperbarui untuk mengikutkan agregasi data dari tabel `reviews` dan `orderItems`.

## 3. Instruksi Pengerjaan untuk AI Agent
1. **Identifikasi File Fetching:** Cari file yang menangani query produk untuk halaman "Semua Produk" (misalnya `app/semua-produk/page.tsx`, `app/products/page.tsx`, atau file terpisah di folder `actions/` atau `services/`).
2. **Samakan Logika Query:** Ubah Prisma query di file tersebut agar menyertakan logika agregasi (rata-rata bintang dan total terjual) yang sama persis dengan yang sudah diterapkan di halaman beranda (hasil kerja PRD-027).
3. **Mapping Data:** Pastikan hasil query dari backend di-map dengan benar sebelum dilempar sebagai props ke komponen `ProductCard`.
4. **Validasi Tampilan:** Pastikan susunan UI `[Icon Bintang Kuning] [Angka] | [Terjual X]` muncul secara konsisten dan tidak merusak layout grid yang sudah ada.

## 4. Acceptance Criteria (Kriteria Selesai)
- Card produk di halaman "Semua Produk" menampilkan rating dan jumlah terjual secara dinamis dari database.
- Jika produk belum ada ulasan/terjual, tangani dengan elegan (misalnya sembunyikan atau tampilkan "Belum ada ulasan" sesuai standar desain sebelumnya).
- Tidak ada error Hydration atau N+1 query problem.
